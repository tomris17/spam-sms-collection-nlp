This repository contains a Natural Language Processing (NLP) solution for classifying text messages as either spam or legitimate (ham) using the UCI Spam SMS Collection dataset.

---

## 📊 Project Overview
* **Objective:** Build an efficient text classification pipeline to detect unsolicited spam messages.
* **Key Steps:**
  * Text cleaning and preprocessing (removing punctuation, lowercase conversion, and stopword removal).
  * Feature extraction using **TF-IDF Vectorization** (Term Frequency-Inverse Document Frequency).
  * Model Training using classification algorithms (Naive Bayes, Logistic Regression, or Support Vector Machines).
  * Interactive web dashboard deployment via **Streamlit** for real-time spam detection.
